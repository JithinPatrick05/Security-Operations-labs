# SOC Tickets

## Ticket 1 - PowerShell User Discovery

**Severity:** Medium  
**Status:** Closed as benign lab activity

### Alert Summary

A PowerShell session executed `whoami.exe` on the Windows 10 victim endpoint to identify the current user context.

### Evidence

```text
Host: DESKTOP-3JKM5O9
User: DESKTOP-3JKM5O9\mmajeed
Process: C:\Windows\system32\whoami.exe
Parent: C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe -Command whoami
Process ID: 7980
Parent Process ID: 8272
Log source: Microsoft-Windows-Sysmon/Operational
Event ID: 1
```

### Analysis

`whoami` is common in troubleshooting and administration, but it is also a discovery command an attacker may use after initial access to identify the current user context.

In this lab the activity was generated by the authorised activity loop, and no suspicious follow-on behaviour was identified in the reviewed event context.

### Verdict

**Benign by context / suspicious by technique**

### Recommended Production Check

Review surrounding PowerShell activity, nearby logons, privilege-related events and other discovery commands before closing an unexpected occurrence.

## Ticket 2 - Local Administrators Group Enumeration

**Severity:** Medium  
**Status:** Closed as benign lab activity

### Evidence

```text
Host: DESKTOP-3JKM5O9
User: DESKTOP-3JKM5O9\mmajeed
Process: C:\Windows\system32\net1.exe localgroup administrators
Parent: C:\Windows\system32\net.exe localgroup administrators
Process ID: 9992
Parent Process ID: 1804
Log source: Microsoft-Windows-Sysmon/Operational
Event ID: 1
```

### Analysis

The command enumerates members of the local Administrators group. That can be normal administrative activity, but it is also relevant during privilege discovery.

Windows commonly invokes `net1.exe` during `net.exe` execution, so seeing both processes is expected.

No account creation, administrator-group modification or unauthorised follow-on activity was identified in the reviewed lab context.

### Verdict

**Benign by context / suspicious by technique**

### Recommended Production Check

Confirm whether the user was expected to enumerate local administrators and review nearby Windows Security events for account creation or group membership changes.

## Ticket 3 - curl.exe Launched from PowerShell

**Severity:** Medium  
**Status:** Closed as benign lab activity

### Evidence

```text
Host: DESKTOP-3JKM5O9
User: DESKTOP-3JKM5O9\mmajeed
Process: C:\Windows\system32\curl.exe https://github.com
Parent: C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe
Process ID: 9900
Parent Process ID: 8272
Log source: Microsoft-Windows-Sysmon/Operational
Event ID: 1
```

### Analysis

Command-line web tools are legitimate for testing and administration but can also be used to download payloads, contact external infrastructure or transfer data.

The destination in this lab was GitHub and no suspicious follow-on execution was identified for this ticket.

### Verdict

**Benign by context / suspicious by technique**

### Recommended Production Check

Review destination reputation, requested/downloaded content, parent process, user context and any process execution that followed.

## Ticket 4 - DNS Lookup to GitHub

**Severity:** Low  
**Status:** Closed as benign lab activity

### Evidence

```text
Host: DESKTOP-3JKM5O9
User: DESKTOP-3JKM5O9\mmajeed
Process: C:\Windows\system32\nslookup.exe github.com
Parent: C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe
Process ID: 1616
Parent Process ID: 8272
Log source: Microsoft-Windows-Sysmon/Operational
Event ID: 1
```

### Analysis

The log proves that `nslookup.exe github.com` executed. It does not by itself prove successful resolution unless the DNS result is reviewed separately.

The command was expected as part of the lab activity loop.

### Verdict

**Benign by context**

### Recommended Production Check

Investigate further if the queried domain is suspicious, newly registered, associated with known malicious activity, or appears alongside download/execution behaviour.

## Ticket 5 - Failed Local Logon

**Severity:** Low  
**Status:** Closed as benign user activity

### Evidence

```text
Host: DESKTOP-3JKM5O9
User: DESKTOP-3JKM5O9\mmajeed
Log source: Windows Security
Event ID: 4625
Timestamp: 2026-05-22 21:00:17.106
Observed failures in reviewed context: 1
```

Fields considered for production triage:

```text
TargetUserName
TargetDomainName
LogonType
IpAddress
WorkstationName
Status
SubStatus
FailureReason
```

### Analysis

A single failed logon from a known local user is commonly explained by a mistyped password or other normal authentication error.

No repeated pattern was identified in the reviewed context.

### Verdict

**Benign by context / likely user error**

### Recommended Production Check

Continue monitoring for repeated failures, unusual source IPs, privileged account targeting or a successful logon immediately after repeated failures.
